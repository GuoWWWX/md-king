# Markdown 语法与文档引用

md-king 支持常用 Markdown 标题、列表、表格、引用块、图片、公式和 Mermaid 图表。应用「关于」页有语法速览，本文介绍文档引用的写法和操作。

## 链接和文件

网址中的 `http://` 和 `https://` 可以自动识别；也可使用 `[网站说明](https://example.com)`。本地文档支持标准链接和双链：

```md
[打开文档](设计.md)
[[设计.md]]
[[设计.md|设计说明]]
```

相对路径从当前文件所在目录解析；以 `/` 开头的路径从当前文档仓库根目录解析，例如 `[[/方案/设计.md]]`。跨文件引用限于当前打开的文档仓库；临时文档请先保存到仓库。文件名、路径和标题重命名后，需要相应修改链接。

`![](图片.png)` 用于图片，不用于章节或段落跳转。表格单元格也可以引用图片，或粘贴、拖入图片。

## 章节引用

```md
[[#部署方案]]
[[设计.md#部署方案]]
[[/方案/设计.md#部署方案|查看部署方案]]
[查看部署方案](设计.md#部署方案)
```

点击后打开目标文件，并选中该章节标题及其内容，包含子章节，直到下一个同级或更高层级标题。标题锚点按标题文字生成：英文转小写，空格转连字符，重复标题依次添加 `-1`、`-2`。也可以在目标章节中右键选择「复制章节引用」，获得准确写法。

## 段落引用

在段落末尾加一个唯一的 ID，也可在段落后的独立一行写 ID：

```md
这是需要引用的段落。
它可以包含多行文字。 ^deployment-rule

[[#^deployment-rule]]
[[设计.md#^deployment-rule|部署规则]]
```

ID 使用英文字母、数字和连字符，在同一文件中保持唯一。点击引用会选中目标段落。新增前面的文字不会改变 ID，但删除或重复 ID 会使引用失效。

也可以在目标段落中右键选择「复制段落引用」：软件自动添加并隐藏 ID，然后复制链接。该操作会修改目标文档，记得保存。

## 行范围引用

明确引用源码行号时，使用以下语法。行号从 1 开始，包含空行：

```md
[[设计.md#L127]]
[[设计.md#L127-L130]]
[[#L127-L130]]
[查看原文](设计.md#L127-L130)
```

未设置显示名时，行引用会显示 `line 127` 或 `line 127-130`；跨文件引用会同时显示文件名。点击后选中完整的目标行。超出文档范围时提示引用失效，不跳到其他位置。

选中普通正文中的若干行，右键选择「复制行范围引用」，软件会在首末行末尾写入隐藏锚点，并复制类似下面的链接：

```md
[[/方案/设计.md#^ref-生成的唯一标识|@line]]
```

`@line` 是自动行号显示名：链接根据锚点位置显示当前的 `line 127-130`；在目标范围前插入或删除行，行号会随之更新。锚点随 Markdown 文件保存，不需要另建索引文件；删除锚点会使引用失效。锚点所在行被拆分、合并时，请重新核对范围。

选区涉及代码块，或首末行属于表格、图片、公式分隔符等结构时，「复制行范围引用」使用明确的 `#L127-L130`，避免向结构中插入锚点。这类坐标引用在前方增删行后需要手动调整。

## 表格、引用块和文字格式

上述链接可放在正文、列表、表格、引用块和 Callout 中，也能与加粗、斜体、粗斜体组合：

```md
**[[设计.md#部署方案]]**
*[[设计.md#^deployment-rule]]*
***[[设计.md#L127-L130]]***

> 引用块中的 [[设计.md#部署方案]]

> [!NOTE] 相关说明
> **[[设计.md#^deployment-rule]]**

| 类型 | 引用 |
| --- | --- |
| 章节 | **[[设计.md#部署方案]]** |
| 段落 | *[[设计.md#^deployment-rule]]* |
| 行范围 | ***[[设计.md#L127-L130]]*** |
```

表格中需要自定义显示名时，标准 Markdown 链接 `[显示名](设计.md#部署方案)` 可以避免双链分隔符 `|` 与表格列分隔符混淆。代码块及行内代码中的语法示例保留为代码，不执行跳转。

## 悬停预览与跳转

单独的 `[文字]` 按普通文本显示；文档中有对应的 `[文字]: 地址` 定义时，才作为引用式链接。`[显示名][标识]` 和 `[标识][]` 同样需要匹配的定义。`[显示名](地址)`、`![说明](图片地址)`、`- [ ] 待办事项` 则继续按各自的标准 Markdown 语法处理。

编辑源码时，只有已识别语法的方括号显示为灰色，包括有效 `[[目标]]` 的两层括号；内部文字保留各自的文字样式。普通 `[文字]`、未定义的引用以及 `[]`、`[[]]`、`[[ ]]` 等空括号按正文颜色原样显示。转义和代码中的括号沿用普通文本或代码高亮规则。

将鼠标停在文档引用上，可查看目标文件名、当前行范围和最多 30 行内容摘要；点击链接或预览右上角行号旁的跳转图标，会跳转并选中全部目标内容。摘要按实际内容收缩，较长内容可在摘要区滚动。已打开标签中的未保存内容优先于磁盘文件；未打开的文件从磁盘读取。预览内容中的链接仅作展示，避免从弹窗中误跳转。

同一文件、跨文件的引用均支持编辑和阅读模式。丢失文件、缺失章节或重复段落 ID 会显示错误提示。

## Word / WPS 导出

导出与 Word 预览会隐藏段落 ID 和行锚点，保留文字及强调格式；代码示例内的标识保持原样。文档引用沿用现有导出规则显示目标路径。编辑器中的悬停预览、源码行号定位和选中行为属于 md-king 功能，导出的 DOCX 不提供同样的交互。

### 文字颜色、下划线和段落对齐

用 `[文字]{属性}` 为文字设置局部格式。颜色使用六位十六进制色值；可与链接、加粗、斜体和粗斜体组合，用于正文、表格和引用块：

```markdown
普通文字中的[红色提示]{color="#D32F2F"}。

[***加粗斜体并加下划线***]{.underline color="#2563EB"}

[整段居中]{align="center"}

[整段靠右并显示红色]{align="right" color="#D32F2F"}

## [保持二级标题样式并居中]{align="center"}
```

`align` 支持 `left`、`center`、`right`，作用于整个段落，方括号须包住整段；标题的 `#` 标记留在方括号外，保留原有标题字体和字号。只设置颜色或下划线时可以包住段落中的几个字。直接在 Markdown 源码中填写这些属性；代码块、行内代码中的语法保持原样。

多段内容共同对齐时使用：

```markdown
::: {align="right"}
示例有限公司

2026年10月24日
:::
```

### 签署块

签署块使用一个三列表格描述字段、填写内容和备注，输出时不显示表头、边框或隔行底色：

```markdown
::: {.signature align="right"}
| 字段 | 内容 | 备注 |
| --- | --- | --- |
| 投标人 | 示例公司 | （盖章） |
| 法定代表人或授权代表 | ____ | （签字） |
| 日期 | [待补充]{color="#D32F2F"} | |
:::
```

填写内容为四个及以上连续下划线时，生成固定长度的空白签字线，默认 4 厘米；空单元格保持空白。已有文字需要下划线时使用 `[张三]{.underline}`，或已有的 `<u>张三</u>`。签字线长度由样式决定，不依赖 `_` 的数量。

样式管理器“扩展样式 → 签署块”可设置整体位置、字段与填写内容对齐、填写区域宽度、细线或粗线、下划线颜色、字段/填写/备注文字颜色、行间距及同页控制。默认跟随正文字体、字号和行距，关闭跟随后可单独调整。块上的 `align` 优先于模板；局部文字 `color` 优先于签署块颜色；填写与备注未单独设置颜色时跟随字段颜色。普通表格和普通文本中的连续下划线沿用原来的处理。

这些显式格式用于编辑预览、Word 预览与 DOCX 导出。Word 中的签字线是可编辑的原生下划线制表符。

### 控制 Word 导出的分页与页面方向

签署信息等短段落可放在同页块中；`.with-previous` 同时绑定前一个段落，前面是表格时绑定最后一行，避免签字、日期单独落页：

```markdown
承诺内容最后一段。

::: {.keep-together .with-previous}
投标人：示例公司（盖章）

签字：________________

日期：________________
:::
```

只需保持块内段落在一起时，去掉 `.with-previous`。若内容本身超过一页，Word 仍需分页；块内明确写出的分页也会保留。

宽报价表可使用局部横向区段：

```markdown
普通纵向正文。

::: {.landscape}
## 报价表

| 项目 | 数量 | 单价 | 金额 | 说明 |
| --- | --- | --- | --- | --- |
| 示例 | 10 | 100.00 | 1,000.00 | 示例说明 |
:::

恢复全局页面方向的正文。
```

横向区段自动换页，结束后恢复模板的全局页面方向，页码连续。区段两侧无需额外插入手动分页。以上两种区块控制用于 DOCX 导出，普通 Markdown 本身不携带原 Word 的分节布局。

页码默认从目录后的正文开始；样式管理器可选择从文档首页开始，并设置起始显示页码。带“共 N 页”的页脚按编号范围统计：正文编号不计封面和目录，全文编号则统计全文。目录及动态页码域需在 Word/WPS 中更新，CLI 可使用 `--update-fields`。
