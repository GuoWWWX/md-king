## 一、核心设计哲学与规范原则

MD King 秉持以下三大第一性原理，打造专业、优雅且极简的所见即所得 Markdown 排版体验：

1. **“引用块是透明容器”原则（Transparent Container Rule）**
   > *“引用块就和正常写文档一样，正常写文档支持什么，这里面都要支持。引用块只是包裹了一下，换个颜色而已。”*  
   引用块（`>`）与 Callout 标注块不是语法“黑洞”，而是文档正文的透视包装层。正文所支持的一切元素——多级标题、段落、加粗/斜体、有序/无序/任务列表及多级缩进、行内与块级数学公式、表格、代码高亮、Mermaid 图表——在引用块内部享有**完全同等的语法解析与渲染能力**。

2. **嵌套内聚性与隔离原则（Strict Scope Isolation）**
   - **外层包裹内层**：外层容器（如加粗、斜体、链接、引用）可以合法包裹行内元素或子结构；
   - **地址与代码绝对隔离**：超链接的 URL 目标 `(...)`、双链的目标文档路径 `[[target|...]]`、行内代码 `` `...` `` 属于严格字面量作用域，禁止任何加粗、斜体等排版标记的侵入；
   - **显示名自由排版**：链接显示名 `[...]`、双链显示名 `[[...|label]]` 属于富文本范畴，完整支持加粗、斜体与行内公式。

3. **中文排版优化（Zero-Space CJK Typography）**
   - 彻底打破西方标准 CommonMark 严苛的“左右定界符必须带空格”的陈规；
   - 双星号加粗（`**`）与单星号斜体（`*`）外侧**完全无需空格**，紧贴全角/半角标点（冒号、括号、叹号、引号）与中文字符时均能 100% 正确闭合与渲染。

## 二、语法嵌套层级树（Hierarchy Tree）

以下树形结构清晰展示了 MD King 语法层级体系与合法包含关系：

```text
文档根节点 (Document Root)
├── 1. 块级容器 (Block Containers)
│   ├── 1.1 引用块 (Blockquote: `> `)  [全透明容器，支持所有子块与行内元素]
│   │   ├── 标题 (Headings: `# ~ ######`)
│   │   ├── 段落与行内富文本 (Paragraphs & Inlines)
│   │   ├── 多级无序列表 (Unordered List: `-`, `*`, `+`)
│   │   │   └── 多级缩进演进: • (第1级) ──> ◦ (第2级) ──> ▪ (第3级)
│   │   ├── 多级有序列表 (Ordered List: `1.`, `1)`)
│   │   │   └── 多级编号演进: 1. ──> 1) ──> a)
│   │   ├── 任务列表 (Task List: `- [ ]`, `- [x]`)
│   │   ├── 块级数学公式 (Block Math: `$$...$$`)
│   │   ├── 增强表格 (GFM Table: `| ... |`)
│   │   ├── 围栏代码块 (Fenced Code Block: ```lang ... ```)
│   │   ├── Mermaid 专业图表 (```mermaid ... ```)
│   │   └── 嵌套子引用块 / Callout
│   │
│   ├── 1.2 增强标注块 (Callout: `> [!type] [fold-flag] [Title]`)
│   │   ├── 标题行 (Title Line) [支持加粗、斜体、代码、数学公式]
│   │   └── 卡片正文 (Body) [继承引用块的全部子元素支持]
│   │
│   ├── 1.3 增强表格 (Table: `| A | B |`)
│   │   └── 单元格 (Cell) [仅容纳行内元素，管道符 `|` 在公式/代码中自动保护]
│   │
│   └── 1.4 围栏代码与图表 (Leaf Blocks: Code / Mermaid / Math)
│       └── 内部纯文本，不解析 Markdown 语法标记
│
└── 2. 行内样式与元素 (Inline Elements)
    ├── 2.1 样式修饰器 (Style Wrappers)
    │   ├── 加粗 (Bold: `**text**`)
    │   │   ├── 允许包含: 斜体、删除线、行内代码、行内公式、链接、双链
    │   │   └── 行为: 外侧无需空格，紧贴中文与标点正常闭合
    │   ├── 斜体 (Italic: `*text*` / `_text_`)
    │   │   ├── 允许包含: 加粗、删除线、行内代码、行内公式、链接、双链
    │   │   └── 行为: 外侧无需空格，紧贴中文标点正常闭合
    │   └── 删除线 (Strikethrough: `~~text~~`)
    │       └── 允许包含: 加粗、斜体、行内代码、行内公式、链接、双链
    │
    ├── 2.2 隔离型/叶子行内元素 (Isolated / Leaf Inlines)
    │   ├── 行内代码 (Inline Code: `` `code` ``)
    │   │   └── 严格字面量，其内不解析加粗、斜体、公式、链接；保护管道符 `|`
    │   └── 行内数学公式 (Inline Math: `$E=mc^2$`)
    │       └── 严格 LaTeX 语法，两端禁止空白，保护公式内部的 `*`、`_`、`|`、`[]`
    │
    └── 2.3 超链接与双链 (Hyperlinks & References)
        ├── Markdown 超链接 (`[text](url)`)
        │   ├── 显示文本 `[text]`: 允许包含加粗、斜体、删除线、行内代码、行内公式
        │   └── 链接地址 `(url)`: 严格隔离，禁止任何加粗/斜体语法解析
        └── Obsidian 双链 (`[[target|label]]` / `[[target]]`)
            ├── 显示名 `|label`: 允许包含加粗、斜体、行内代码
            └── 目标路径 `target`: 严格隔离，禁止任何加粗/斜体语法解析
```

## 三、行内样式语法与嵌套支持规范

### 3.1 加粗（Bold / Strong）
- **语法标记**：`**内容**`
- **中文与标点特性**：
  - **外侧无需空格**：无论前接汉字、半角字母还是全角标点，均能自然闭合；
  - 示例：`前缀**重点内容：**后续正文` $\to$ 前缀**重点内容：**后续正文。
- **允许嵌套内容**：
  - 加粗包裹数学公式：`**$f(x) = \sin(x)$**`（星号隐藏，公式正常渲染为粗体）；
  - 加粗包裹行内代码：`**\`npm run build\`**`；
  - 加粗包裹超链接：`**[官方网站](https://example.com)**`；
  - 加粗包裹双链：`**[[产品路线图.md|核心规划]]**`；
  - 加粗包裹斜体：`***粗斜体合一***`。

### 3.2 斜体（Italic / Emphasis）
- **语法标记**：`*内容*` 或 `_内容_`
- **中文与标点特性**：
  - 支持单星号紧邻中文字符与全角标点（如 `*提示：*操作成功`），无需手动补空格；
- **允许嵌套内容**：
  - 斜体包裹公式：`*$O(\log N)$*`；
  - 斜体包裹链接：`*[查看详情](https://example.com)*`。

### 3.3 删除线（Strikethrough）
- **语法标记**：`~~废弃内容~~`
- **特性**：外侧无需空格，支持嵌套公式 `~~$x+y=1$~~` 与链接 `~~[失效链接](...)~~`。

### 3.4 行内代码（Inline Code）
- **语法标记**：`` `代码内容` `` 或 ```` ``两端多反引号`` ````
- **核心约束（隔离区）**：
  - 代码内部为**纯字面量作用域**；
  - 内部出现的 `**`、`*`、`_`、`|`、`$`、`[]` 全部按原样输出，绝不解析为任何排版样式；
  - 在表格单元格中，行内代码内部的管道符（如 `` `a | b` ``）不会被误切分为多列。

### 3.5 行内数学公式（Inline Math）
- **语法标记**：`$LaTeX公式$`
- **排版防误触规范**：
  - **首尾非空白原则**：起始 `$` 后紧邻的字符不得为空格/换行，闭合 `$` 前紧邻的字符不得为空格/换行（例如 `$ a+b $` 为非法，正确写法为 `$a+b$`）；
  - **货币符号防护**：像 `价格为 $5，运费为 $10` 不会误匹配为跨句公式；
- **符号隔离保护**：
  - 公式内部出现的乘号 `*`、下标 `_`、方括号 `[a, b]`、绝对值/条件概率 `|` 属于数学符号，不触发任何 Markdown 语法。

### 3.6 Markdown 超链接（Links）
- **语法标记**：`[显示文本](URL "可选标题")`
- **结构分割原则**：
  - **显示文本 `[...]`**：支持富文本，可嵌套加粗 `[**加粗文本**](...)`、斜体 `[*斜体*](...)`、公式 `[$O(1)$ 查找](...)`；
  - **链接地址 `(...)`**：严格隔离区。URL 中的任意字符（包含 `**`、`_`、`~`）均视为地址本体，绝不触发样式隐藏或破坏。

### 3.7 Obsidian 双链文件引用（Wikilinks）
- **语法标记**：
  - 简短形式：`[[文件名]]`（自动隐藏 `.md`，呈现紧凑文档胶囊卡片）
  - 别名形式：`[[文档路径|显示别名]]`
- **结构分割原则**：
  - **目标路径 `target`**：严格隔离区，禁止任何样式侵入；
  - **显示别名 `label`**：支持加粗与斜体（如 `[[设计文档|**系统核心架构**]]`），在编辑器与 Word 导出中均保持粗体呈现；
  - **外部包裹**：支持加粗外层包裹双链（如 `**[[文档]]**`）。

## 四、块级容器与排版规范

### 4.1 引用块（Blockquote）——“透明容器”原则
- **语法标记**：每行行首以 `> ` 开头。
- **全要素支持清单**：
  1. **标题**：`> ## 引用块内的二级标题`
  2. **正文与行内样式**：`> 包含 **加粗**、*斜体*、`代码` 与 $E=mc^2$ 公式`
  3. **多行数学公式**：
     ```markdown
     > $$
     > \int_{a}^{b} f(x) dx = F(b) - F(a)
     > $$
     ```
  4. **围栏代码块**：在引用块内高亮展示，复制代码时不包含 `>` 前缀；
  5. **Mermaid 图表**：在引用块内完整渲染图表；
  6. **嵌套多级引用**：`> > 二级深层引用`。

### 4.2 增强标注块（Callout）
- **语法标记**：
  ```markdown
  > [!type] [+/-] [自定义标题]
  > 正文内容...
  ```
- **核心特性**：
  - **预置类型**：支持 `note`, `info`, `tip`, `warning`, `danger`, `success`, `question`, `quote`, `bug`, `example` 等 13+ 种类型，具备专属主题图标与边框色彩；
  - **折叠开关**：`+` 表示默认展开，`-` 表示默认折叠，点击标题栏任意位置可平滑收展；
  - **标题行富文本支持**：
    标题行中完整支持加粗、斜体、行内代码与数学公式。
    *示例*：
    ```markdown
    > [!tip] 核心优化：时间复杂度降低至 **$O(\log N)$**
    > 正文详细步骤说明...
    ```

### 4.3 多级列表（有序 / 无序 / 任务列表）

#### 1. 无序列表（Unordered List）
- **标记符号**：`-`、`*`、`+`
- **多级缩进规范**：
  - 缩进单位：2 个空格、4 个空格或 1 个 Tab；
  - **层级圆点符号演变**：
    - 第 1 级（顶层）：实心圆点（`•`）
    - 第 2 级（子列表）：空心圆圈（`◦`）
    - 第 3 级及以上：实心方块（`▪`）
- **引用块内一致性**：在 `> ` 内部书写时，缩进深度与圆点样式演化**与正文完全相同**。

#### 2. 有序列表（Ordered List）
- **标记符号**：`1.`、`2.` 或 `1)`、`2)`
- **多级编号演化**：
  - 第 1 级：阿拉伯数字加点（`1.`、`2.`、`3.`）
  - 第 2 级：阿拉伯数字加括号（`1)`、`2)`、`3)`）
  - 第 3 级：小写字母加括号（`a)`、`b)`、`c)`）
- **智能重排**：在编辑过程中自动保持编号连续性。

#### 3. 任务列表（Task List）
- **标记符号**：`- [ ] 未完成任务`、`- [x] 已完成任务`
- **交互**：在实时预览中可直接使用鼠标点击切换完成状态，自动同步修改底层 Markdown 源码。

### 4.4 增强表格（Table）与管道符隔离
- **语法标记**：GFM 标准表格 `| 标题 | 标题 |`
- **单元格格式化支持**：
  - 单元格内支持加粗、斜体、删除线、行内代码、行内数学公式、超链接、双链；
- **管道符 `|` 智能保护隔离**：
  - 行内代码中的管道符（如 `` `a | b` ``）不会被当成分列符；
  - 数学公式中的管道符（如 `$P(A|B)$`、`$|x|$`）不会破坏表格分列；
  - 双链中的管道符（如 `[[doc|别名]]`）不会破坏表格分列。

### 4.5 围栏代码块（Fenced Code Block）
- **语法标记**：
  ````markdown
  ```typescript
  const message: string = "Hello MD King";
  console.log(message);
  ```
  ````
- **特性**：
  - 语法高亮、右上角显示编程语言标签；
  - 提供一键复制代码按钮，自动去除多余的前缀与围栏。

### 4.6 独立块级数学公式（Block Math）
- **语法标记**：
  ```markdown
  $$
  f(x) = \int_{-\infty}^{\infty} \hat{f}(\xi)\,e^{2 \pi i \xi x}\,d\xi
  $$
  ```
- **特性**：居中展示，支持复杂矩阵、方程组与编号。在正文与引用块中均原生支持。

## 五、Mermaid 图表语法与交互规范

MD King 内置强大的专业级 Mermaid 渲染引擎（Mermaid v11+），并针对桌面交互与主题做了专项增强：

### 5.1 流程图（Flowchart）与子图（Subgraph）防遮挡
- **基础语法**：
  ```mermaid
  flowchart TD
      Start([开始]) --> Step1[步骤一]
      Step1 --> Step2{判断条件}
      Step2 -- 是 --> End([结束])
      Step2 -- 否 --> Step1
  ```
- **子图防遮挡规范（SubGraph Clearance）**：
  MD King 专门优化了子图标题与内部节点的垂直间距：
  - 无论子图标题为单行、中文长标题折行，还是存在多层嵌套子图（Nested Subgraph）；
  - 系统自动分配足够的安全避让槽位（Clearance Margin），**确保卡片顶部居中的文字绝不被内部任何子卡片遮盖**。

### 5.2 时序图（Sequence Diagram）
- **特性**：支持参与者（actor）、生命线、同步/异步消息、便签（Note）、循环块（loop）与分支选择（alt/opt）。

### 5.3 状态图（State Diagram）
- **语法**：`stateDiagram-v2`
- **特性**：支持起始/结束状态、状态转移说明、复合状态（Nested States）与并发状态（Fork/Join）。

### 5.4 类图（Class Diagram）与实体关系图（ER Diagram）
- **类图**：类名、属性、方法、继承/实现/组合/聚合关系及重数标记；
- **ER 图**：实体定义、键属性（PK/FK）以及一对一、一对多关系连线。

### 5.5 图表交互规范（划选复制与超链接点击）
- **文本划词选中与复制（Text Selection & Copy）**：
  - 鼠标悬停在图表内的文字（节点标签、标题、连线文字）上呈现文本光标（`cursor: text`）；
  - **支持鼠标直接拖选（拖蓝）选中文本，按 `Ctrl+C` 即可复制**；
  - 拖拽过程平滑稳定，**绝不会闪退或折叠回 Markdown 源码**。
- **图内超链接点击（Interactive Links）**：
  - 支持 Mermaid 官方的 `click` 语法与 `href` 属性；
  - 鼠标悬停在带链接节点上呈现手型光标（`cursor: pointer`），点击可平滑在外部浏览器或对应文档中打开。

### 5.6 亮色 / 深色模式自适应规范
- **亮色模式（Light Mode）**：
  清新柔和的容器背景，高对比度深色文本（`#111827` / `#334155`），清晰明快的节点边框与连线；
- **深色模式（Dark Mode）**：
  - 自动切换为高对比度自适应色系；
  - **全图表文字清晰可见**：子图标题、节点文本、连线说明、状态图标签、时序图便签与循环条件均自动切换为柔和白/浅灰文字（`#e2e8f0` / `#f8fafc`）；
  - 彻底杜绝“黑底黑字”看不清的隐形文本问题。
