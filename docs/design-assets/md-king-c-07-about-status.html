MD King Desktop

v2.4.0 Pro

专为现代 AI 时代设计的文档转换引擎。将纯文本、Markdown 及代码块，安全、快速、本地化地转换为排版精良的专业级 Microsoft Word 及 PDF 交付物。

verified 正版授权 update 上次更新: 2023.10.15

核心能力 (Core Capabilities)

content_paste

粘贴转换 (Paste & Convert)

一键捕获剪贴板中的多态 Markdown 并结构化重组。

library_books

批量文件 (Batch Processing)

拖拽文件夹，支持高并发多线程后台静默转换。

format_paint

模板样式 (Template Styles)

基于参考 .docx 文件，完美映射标题、正文及表格样式。

edit_document

轻量编辑 (Lightweight Editing)

内置双栏所见即所得编辑器，转换前微调元数据。

terminal

Agent/CLI (Developer Tools)

提供命令行接口及本地 API，便于集成至自动化流。

隐私安全承诺 (Local Execution Guarantee)

MD King 采用 100% 本地离线执行架构。您的所有文本、提示词生成内容及转换后的文档，均在本地内存中处理并直接写入本地磁盘。应用不会向任何云端服务器上传、遥测或备份您的业务数据。
